# Банки вопросов — инструкция для фронтенда

Базовый префикс API: **`/cs/v1`**

Пока нет авторизации по JWT — идентификатор пользователя передаётся явно (в query или в теле запроса, где это требуется бизнес-логикой).

---

## Банки вопросов

| Метод | URL |
|-------|-----|
| GET | `/cs/v1/banks?user_id={userId}` |
| POST | `/cs/v1/banks` |
| PUT | `/cs/v1/banks/{bankId}` |
| DELETE | `/cs/v1/banks/{bankId}` |

### Просмотр списка банков преподавателя

1. `GET /cs/v1/banks?user_id={userId}` — получить все банки, принадлежащие пользователю.
2. В каждом элементе списка доступно количество вопросов в банке (`questionsCount`) — можно показывать в карточке/таблице без отдельного запроса.

### Создание банка

1. `POST /cs/v1/banks` — создать новый банк для пользователя.
2. После успешного ответа можно перейти к наполнению банка вопросами.

### Редактирование банка

1. `PUT /cs/v1/banks/{bankId}` — изменить название и описание.
2. Владелец банка проверяется по `userId` в теле запроса: обновление выполняется только если он совпадает с владельцем банка в БД. Передать чужой `userId` нельзя — запрос не обновит банк.

### Удаление банка

1. `DELETE /cs/v1/banks/{bankId}` — удалить банк целиком.
2. Все вопросы и ответы внутри банка удаляются каскадно.

## Вопросы в банке

| Метод | URL |
|-------|-----|
| GET | `/cs/v1/bank_questions?bank_id={bankId}` |
| POST | `/cs/v1/bank_questions` |
| PUT | `/cs/v1/bank_questions/{questionId}` |
| DELETE | `/cs/v1/bank_questions/{questionId}` |
| POST | `/cs/v1/bank_questions/bulk` |
| PUT | `/cs/v1/bank_questions/{bankId}/bulk` |

### Просмотр вопросов банка

1. `GET /cs/v1/bank_questions?bank_id={bankId}` — список всех вопросов выбранного банка с вариантами ответов.

### Добавление одного вопроса

1. `POST /cs/v1/bank_questions` — создать вопрос с ответами в указанном банке.
2. Подходит для формы «добавить вопрос» на странице редактирования банка.

### Редактирование одного вопроса

1. `PUT /cs/v1/bank_questions/{questionId}` — обновить текст, тип, баллы и полный набор ответов.
2. При обновлении старые ответы заменяются новым списком из запроса — фронту нужно отправлять актуальный полный список ответов, а не только изменённые.

### Удаление одного вопроса

1. `DELETE /cs/v1/bank_questions/{questionId}` — удалить вопрос и связанные с ним ответы.

### Массовое создание вопросов

1. `POST /cs/v1/bank_questions/bulk` — создать несколько вопросов за один запрос.
2. Удобно при импорте из файла или мастера добавления нескольких вопросов подряд.

### Полная замена всех вопросов в банке

1. `PUT /cs/v1/bank_questions/{bankId}/bulk` — удалить все текущие вопросы банка и записать новый полный список.
2. Использовать, когда нужно синхронизировать банк с внешним источником или сохранить черновик «целиком», а не точечными правками.
3. **Не смешивать** с поштучным редактированием без необходимости: bulk-замена перезаписывает всё содержимое банка.

## Типовые сценарии на UI

### Экран «Мои банки вопросов»

```
GET /banks?user_id=…  →  таблица банков (title, questionsCount, …)
```

### Экран «Редактор банка»

```
GET /bank_questions?bank_id=…     →  загрузка списка вопросов
POST /bank_questions              →  кнопка «Добавить вопрос»
PUT /bank_questions/{id}          →  сохранение карточки вопроса
DELETE /bank_questions/{id}       →  удаление вопроса
PUT /banks/{bankId}               →  сохранение названия/описания банка
```

### Импорт набора вопросов в новый или существующий банк

```
POST /banks                       →  (если банка ещё нет)
POST /bank_questions/bulk         →  загрузка пакета вопросов
```

### Полная перезапись содержимого банка

```
PUT /bank_questions/{bankId}/bulk →  заменить все вопросы новым набором
```

---

## Связь с тестами

Банки вопросов принадлежат **пользователю**, а не курсу. При создании теста в теле запроса на тест указываются идентификаторы банков (`bankIds`), из которых генерируются вопросы попытки. Один банк может использоваться в тестах разных курсов одного преподавателя.
